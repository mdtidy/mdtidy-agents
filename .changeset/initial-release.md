Initial release of the mdtidy MCP server. Ships the universal stdio + Streamable-HTTP
server with the v1 tool surface: `tidy_markdown` (clean + convert to
HTML/text/PDF/DOCX/PNG), the `save_document` upsert fast-path, and the curated
read/write/share workspace tools. Generated from the live mdtidy OpenAPI contract.
